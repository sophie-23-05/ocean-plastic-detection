# 🌊 Ocean Plastic Waste Classifier

## 📘 Project Overview
Marine pollution is one of the most critical global environmental challenges today. This project aims to **identify floating plastic waste in ocean images** using **Deep Learning and Transfer Learning** techniques.  
The model classifies uploaded images into **three categories** — Plastic Cover, Other Plastics, and Metal Waste.

This project not only supports sustainable ocean monitoring but also demonstrates how Artificial Intelligence can play a vital role in environmental conservation.

---

## 📊 Dataset
**Source:** [Underwater Plastic Pollution Detection – Kaggle Dataset](https://www.kaggle.com/datasets/arnavs19/underwater-plastic-pollution-detection)

**Author:** Arnav S.  
The dataset contains underwater images of plastics and other debris for environmental research.
